# DS2 Class Roller

A simple class roller for Dark Souls II, mainly made for use with the DS2 Randomizer mod.

## What it does

This tool randomly selects a class and starting gift for a Dark Souls II run.

## Usage

Run the project and press the roll button to get a random class and starting gift.

## Notes

Made for personal use with the DS2 Randomizer mod.
