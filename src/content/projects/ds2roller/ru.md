# DS2 Class Roller
Простой роллер класса для Dark Souls II, созданный в первую очередь для использования с модом DS2 Randomizer.
## Что делает
Инструмент случайным образом выбирает класс и стартовый подарок для прохождения Dark Souls II.
## Использование
Запустите проект и нажмите кнопку ролла, чтобы получить случайный класс и стартовый подарок.
## Заметки
Сделан для личного использования с модом DS2 Randomizer.
