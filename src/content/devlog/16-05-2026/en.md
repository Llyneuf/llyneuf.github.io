The new VTuber character is moving from rough shape into something that can actually be used. The base is ready enough to start thinking about the body, face and how the model should feel in motion.

This stage is still experimental: proportions, silhouette, expressions and small visual details matter more than polish. The goal is to find a character direction that feels readable on stream and still leaves room for future upgrades.

Once the main model direction is stable, the next work will be cleanup, rigging tests and checking how the character behaves in the tools I want to use.
